**Compliance Insurance Agents**
---

This package provides a modular set of insurance-focused compliance agents designed to review content, apply global and product-specific rules, and return a unified, well-structured assessment. Each agent focuses on a specific insurance domain, while a central workflow orchestrates routing, merging, and output generation.
All agents accept raw text, uploaded files, or structured objects. Results are consolidated into a single, human-readable report with optional rewrite guidance and tooling for downstream formatting.

Features
* Global + product-level compliance layers
* Region-aware logic
* Flexible input formats
* Unified merged output
* Simple workflow-based orchestration
